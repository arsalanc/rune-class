Multiplayer (beta)
Your friend hosts the world in their browser. Ask them for the World ID, plus the invite code the first time you play — after that your own password is all you need.
The world runs in this tab and stops when you close it. Keep it open and visible — a backgrounded tab is throttled by the browser and the world will run choppily for everyone.
Connects to a Node server run from server/ with npm start. No password — fine on a LAN, don't expose it to the internet.
Shared gathering, combat & chat. Banking, smithing, quests & magic stay singleplayer for now.
